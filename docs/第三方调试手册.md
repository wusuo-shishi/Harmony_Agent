## 2. 快速跑通(模拟器,10 分钟)

```powershell
# 1) 打开工程
#    DevEco Studio → File → Open → 选工程根目录(Harmony_Agent)

# 2) 同步依赖(右下角 Sync 图标,或 File > Sync and Refresh Project)

# 3) 启动模拟器(DevEco Device Manager 里选已装镜像启动;命令行):
devecocli emulator list
devecocli emulator start "nova 15 Pro"

# 4) 运行 App(DevEco 点 Run;或命令行):
devecocli run --skip-build --device 127.0.0.1:5555
```

**模拟器可验证的功能**(对照 `docs/真机验收用例清单.md`):
- 聊天 + Mock 回复(`你好`)
- 学习助手:`引用溯源是什么` → 带引用来源回答
- 日程管家:`明天下午3点开组会提醒我` → 内存日程提示(注意:模拟器写不了系统日历)
- 文档处理:点【识图】 → 内置文本样例 → 总结 → 入库
- 知识库页:检索 `引用溯源` / `语音热词` / `跨设备协同`;敏感词拦截
- 本地单测:右键 `entry/src/test/List.test.ets` → Run(27 条断言,不依赖设备)

## 3. 真机签名(真机联调前必须完成)

模拟器不需要签名,真机必须。任选其一:

**方式 A(推荐,自动)**:DevEco → File → Project Structure → **Signing Configs** → 勾选 **Automatically generate signature** → Apply。成功后 `build-profile.json5` 会出现 `signingConfigs` 字段(此前构建日志会提示 "skip sign",属正常)。

**方式 B(命令行)**:先 `devecocli auth login`(华为账号),再在工程根目录执行 `devecocli signature generate`,会把签名写入 `build-profile.json5`。

> 若真机报 `error:install sign info inconsistent`:说明签名换过,先 `devecocli run --uninstall` 或删掉设备上旧包再装。

**验证**:DevEco Device 下拉框能看到设备且能 Run 到真机 = 签名就绪。

## 4. 真机联调顺序(按里程碑)

### 4.1 D3 语音识别(优先,手机)

详细排错表见 `docs/D3语音真机联调手册.md`。要点:

1. 入口:首页底部【语音】。
2. **首次点击【语音】才申请麦克风权限**(D8 已改:启动不再弹权限框)。真机应正常弹系统授权框 → 允许。
3. 权限已被拒时的提示会引导去系统设置开启(设置 → 应用 → 本应用 → 权限)。
4. 语料(见验收清单 2 节),从"停止说话"到"文字上屏"计时,目标 ≤2s。
5. **如授权框一直不弹或静默失败**,hilog 里查 `MicPerm`(见 §5),正常真机 `dialogShownResults` 应为 true。

### 4.2 D4.5 知识库真机验证

手机/平板均可,对照验收清单第 3 节 TC-D4-1~14,含文件导入(用 `hdc file send` 推一个 md/txt 到 Download 再导入)。

### 4.3 D6 真机路径复核(重点新功能)

| 能力 | 验证点 | 入口 | 预期 |
| --- | --- | --- | --- |
| OCR | 用手机拍一张有文字的纸稿 | 首页【识图】→ 拍照/相册 | 正确识别并总结,知识库新增文档 |
| 系统日历 | 说/输入 `明天下午3点开组会提醒我` | 日程管家 | 打开系统日历能看到该日程+提醒 |
| 一多双栏 | 平板/折叠屏打开首页 | — | 宽度≥840vp 时右侧并排知识库面板 |

> OCR/日历在模拟器走的是降级实现,真机首次跑通时若报错,把 hilog(见 §5)发回,重点看 `MicPerm`、OCR 的错误码(100140xxxx)与日历 2390xxxx。

### 4.4 D5 DataAugmentationKit(需 PC/2in1 + 手机/平板)

原理见 `docs/design.md` §3.2。一句话:**知识加工只在 PC/2in1 跑,手机/平板用 retrieval 检索,完整 rag API 在 PC/2in1 演示**。
- 本仓库目前 D5 只留 `DagRetrievalProvider` 占位 + 自研关键词检索兜底;真机接入请按 design §3.2 与华为官方 DataAugmentationKit 文档实现。

### 4.5 D7 跨端接续(手机↔平板,可选)

目标:双设备同账号组网,聊天会话通过应用接续流转。当前代码仅有一多布局;接续为后续里程碑,本次联调如设备未组网可跳过。

## 5. 通用排障(日志怎么抓)

### 5.1 拉 App 日志

```powershell
# 方式1:devecocli(常用)
devecocli log --keyword <关键词> --tail 200 --device <设备序列号>
# 若 devecocli log 参数报错,退回 hdc 直连:

# 方式2:hdc 直连
# hdc 位于 DevEco 自带 SDK:用 DEVECO_HOME 定位,不要写死路径
$hdc = Join-Path $env:DEVECO_HOME "sdk\default\openharmony\toolchains\hdc.exe"
& $hdc shell "hilog -x -T MicPerm"        # 实时看某 Tag(MicPerm/PerfLaunch/testTag)
& $hdc shell "hilog -x | findstr 2390"    # 含错误码过滤
```

### 5.2 预置日志 Tag

| Tag | 模块 | 用途 |
| --- | --- | --- |
| `PerfLaunch` | EntryAbility | 冷启动各阶段耗时(onCreate / onWindowStageCreate / content loaded,单位 ms) |
| `MicPerm` | 语音权限 | 授权回调原始 JSON(含 `authResults` / `dialogShownResults`) |
| `testTag` | 各处示例 | 通用 |

### 5.3 冷启动耗时口径

看 hilog `PerfLaunch`:`Index content loaded at N ms` 即 loadContent 完成时刻。目标(命题)从点击图标到可交互 ≤3s;真机若有偏差,优化点为:懒加载语音引擎/检索会话(design §5)。

### 5.4 常见错误速查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 构建 `skip sign` | 无签名 | 见 §3 |
| 装真机 `sign info inconsistent` | 签名/旧包 | uninstall 后重装 |
| 语音授权框不弹 | 模拟器不支持 / 真机设置已拒 | 模拟器属正常;真机去设置授权 |
| OCR 抛 100140xxxx | CoreVision 服务异常/超时 | 重试;确认真机系统与网络;抓 hilog |
| 日历写不进 2390xxxx | 权限拒绝 / 无日历账号 | 允许 WRITE_CALENDAR;或用默认本地日历 |
| 模拟器跑 Agent 无 OCR | 模拟器无 CoreVision | 属预期(内置文本降级),真机复测 |
| `AccessToken` 不是命令 | PowerShell 把 `\|` 当管道 | 命令整体加引号或单独关键词 |
