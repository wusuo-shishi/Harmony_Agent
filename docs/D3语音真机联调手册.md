# D3 语音功能 · 真机联调操作手册

目标:在华为真机(HarmonyOS NEXT,API≥22,建议 6.x)上验证"语音→识别文字→填入输入框→发送对话"链路。

## 0. 前置条件(本机需要)
- DevEco Studio(与本工程 SDK 版本匹配,≥6.1.0 即可打开工程)
- 已登录**华为开发者账号**(用于自动签名)
- 手机开启 **开发者模式 + USB 调试**,用数据线连电脑
- 手机系统保持 HarmonyOS NEXT,不要退回旧版

## 1. 打开工程并配置签名(只做一次)
1. DevEco 打开工程目录:`D:\MyCode\DevEcoStudioProjects\Harmony_Agent`
2. 顶部菜单 `File > Project Structure > Signing Configs`
3. 勾选 `Automatically generate signature`,按提示登录华为账号(需实名)
4. 点击 Apply,此时会生成 p7b/p12/cer,写入 build-profile.json5
5. 如提示"未检测到设备",先确保手机已连上(见步骤 2)

## 2. 连接真机
1. 手机:`设置 > 关于手机 > 连点版本号` 开启开发者模式
2. `设置 > 系统与更新 > 开发人员选项 > USB 调试` 打开
3. 插线后在手机上点"允许 USB 调试"
4. DevEco 右上角 Device 下拉里应出现你的手机(型号名);若没有,重启 DevEco 或换数据线

## 3. 运行到真机
1. Device 下拉选中真机(不是模拟器)
2. 点 Run(三角)或 `Build > Run 'entry'`
3. 首次运行会请求**麦克风权限**,请点"允许"(代码在 App 启动时自动请求)

## 4. 语音功能测试步骤
1. App 打开后,输入框左侧点**【语音】按钮 → 变红色“停止”**,表示正在听
2. 对着手机说一句中文,如:"帮我总结一下今天会议的重点"
3. 观察:识别文字应**实时**填入输入框(中间结果),说完停顿约 1.5–2s 后自动结束并保留最终文本
4. 点【发送】,应收到 LLM 回复(默认 Mock;需真模型时把 LlmConfig.ets 的 ENABLE_DEEPSEEK 改 true)
5. 再点【语音】期间想终止,可直接点【停止】

## 5. 预期与验收
| 检查项 | 预期 |
| --- | --- |
| 权限弹窗 | 启动时出现一次,允许后不再弹 |
| 点击语音 | 按钮变红"停止",无报错弹窗 |
| 说话转写 | 普通话短句实时上屏 |
| 静音停顿 | 约 1.5–2 秒后自动结束,最终文本正确上屏 |
| 发送 | 走正常对话流程 |

## 6. 常见问题
| 现象 | 处理 |
| --- | --- |
| 点击语音弹"语音引擎启动失败" | ① 真机系统是否 HarmonyOS NEXT?② 引擎不支持该版本时换 6.x 设备;③ 查看 hilog 报错码 |
| 权限未弹/被拒 | `设置>应用>应用助手`里允许麦克风,或卸载重装 |
| 识别中途自动停 | 属 VAD 停顿设置,已调 vadBegin=1500ms;仍觉得短可告诉我加大 |
| 报错 1002200001 | 引擎创建失败(语种/资源/被占用),多为模拟器或低版本系统,须真机 |
| 报错 1002200006 | 引擎忙(其他 App 占用),关掉其他语音应用重试 |
| 识别不精准 | 这是预期优化项:后续用"热词"调优;先记录识别错误的词/句反馈给我们 |

## 7. 需要反馈给主线的信息
1. 设备型号 + 系统版本(设置>关于手机)
2. 能否弹出权限框、是否允许成功
3. 点语音后是否报错(截图/日志:`devecocli log` 或 DevEco Log 里搜 testTag)
4. 3 句测试语料各自的识别结果(对/错/误差词)
5. 从"说完到文字上屏"的主观时延(快/中/慢)
