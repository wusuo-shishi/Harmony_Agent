# 真机验收用例清单(验收官版)

用途:手机/平板真机验收官按此清单装包实测,反馈录屏/截图/数据给编码核心与文档角色。
配套:
- 语音联调细节见 `docs/D3语音真机联调手册.md`
- 总方案/里程碑见 `docs/design.md`
- 当前重点:D3 语音真机 + D4 知识库真机(D4.5);D6 智能体已在模拟器回归通过,真机需复核日历/OCR 真实路径;后续 D5/D7 小节将随里程碑补全

## 0. 使用规则

1. 每条用例编号 `TC-Dx-y`,按表格逐项执行并填"结果/证据"。
2. 截图命名:`TC编号_设备_日期_序号.png`,例 `TC-D3-2_手机_0904_01.png`。
3. 关键操作全程录屏(语音、跨端场景必须录屏)。
4. 问题上报用下方"问题单"模板,反馈越快主线越早修。
5. 未通过/有偏差的用例不要自己改代码,只在问题单里写清楚。

## 2. D3 语音验收(优先手机)

入口:App 首页聊天输入框左侧【语音】按钮。

| ID | 步骤 | 预期 | 结果/证据 |
| --- | --- | --- | --- |
| TC-D3-1 | 冷启动 App,首次进入 | 弹出麦克风权限,允许后不再弹 | |
| TC-D3-2 | 点击【语音】 | 按钮变红显示"停止",无报错弹窗 | |
| TC-D3-3 | 说出"帮我总结一下今天会议的重点"(可加系统词) | 识别文字实时填入输入框(中间结果) | |
| TC-D3-4 | 说完停顿约 1.5–2s | 自动停止,最终文本正确保留 | |
| TC-D3-5 | 说一句后立即点【停止】 | 立即停止,保留已识别文字 | |
| TC-D3-6 | 上屏文本后点【发送】 | 走对话流程并收到回复(默认 Mock) | |
| TC-D3-7 | 用下方 3 句语料各测一次 | 记录逐字转写结果与"快/中/慢"时延 | |

语音语料(请大声、普通话、安静环境):
1. 帮我总结一下今天会议的重点
2. 把下周三下午三点的组会提醒我
3. 打开知识库,检索引用溯源是什么

时延口径:从"停止说话"到"最终文字上屏"用时;主观快(<1s)/中/慢,如能用秒表给秒数更好。

常见问题对照:D3 手册 §6(引擎报错 1002200001/0006、权限、识别不准等)。

入口:首页右上角【知识库】。

| ID | 步骤 | 预期 | 结果/证据 |

### 3.2 检索与引用溯源(核心)
用下方 Query 依次检索,逐条记录截图:
| ID | Query | 预期(返回卡片含文档标题/分块号/命中数/原文偏移) |
| --- | --- | --- |
| TC-D4-5 | 引用溯源 | 命中《端侧 RAG 与引用溯源说明》 |
| TC-D4-6 | 语音热词 | 命中《日程管家与语音热词说明》 |
| TC-D4-7 | 跨设备协同 | 命中《鸿蒙多模态个人助理产品说明》 |
| TC-D4-8 | 无意义词如"天气预报" | 提示"未命中相关文档…",不返回结果 |
| TC-D4-9 | 敏感词(如"如何参与刷单") | 提示"输入包含敏感词…已拦截本次检索",不检索 |
| TC-D4-10 | 连续点几次检索 | 结果卡片正确刷新,无卡死/重复堆积 | 

引用核对:对 TC-D4-5/6/7 各取一条命中,对照卡片片段与"原文偏移",确认片段确实来自对应文档(可删除其他文档后复检唯一来源)。

时延口径:从点【检索】到结果卡片出现;主观快/中/慢,记录最慢一条。

### 3.3 文件导入

- 电脑命令行推送:`hdc file send 本地路径 /storage/Users/currentUser/Download/课程安排.md`(若路径提示不存在,以手机文件管理实际目录为准)
